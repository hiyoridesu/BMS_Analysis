# BMS 谱面分析系统 — 方案设计文档

> 本文档为系统实现前的完整方案设计，包含项目范围、解析规则、算法细节、可视化方案与系统架构。

---

## 一、项目概述

### 1.1 项目目标
构建一个面向玩家的 BMS 谱面分析系统，统计谱面键位数量、密度分布，识别键型配置，结合 BGM 部分进行段落划分（已简化为固定15秒分段），输出可视化分析报告（PDF）。

### 1.2 目标用户
**玩家**（用于了解谱面特性、辅助选择适合自己的谱面）

### 1.3 项目范围

| 项 | 内容 |
|---|---|
| 支持格式 | BMS、BME、pms（统一逻辑处理，**不含 BMSON**） |
| 谱面模式 | 7key + 1 Scratch（7k 模式） |
| 限制条件 | 不含变速、仅处理正规谱面（不处理 `#RANDOM` 等预处理指令） |
| LN 支持 | 兼容通道 51~59 与 LNOBJ；仅统计开始点，持续时间不影响难度 |
| 输入 | 单个 BMS 文本文件（网页上传） |
| 输出 | PDF 分析报告（默认文件名基于谱面文件名） |

---

## 二、BMS 解析规则

### 2.1 时间轴
- 基于 BPM 换算为秒：`时间(秒) = (位置 / 分辨率) × (60 / BPM)`
- 显示时同时给出**播放时间（秒）**和**小节数**

### 2.2 轨道处理

| 轨道 | 用途 |
|---|---|
| 11~19 | 谱面音符（7 键 + Scratch） |
| 51~59 | LN（长押）通道 |
| 01 | BGM（用于段落划分相关统计） |

### 2.3 LN 处理
- 兼容通道 51~59 与 LNOBJ 两种 LN 表达方式
- **仅统计 LN 开始点**，持续时间不影响任何难度计算

---

## 三、键型识别规则

一个音符可同时属于多种键型（**不去重**），键型复合是难度的重要因素。

### 3.1 纵连（Jack）
- **定义**：同一轨道连续两音符开始时间间隔 < 8分音符（含符合时值的切分音）
- **最小连击数**：2
- **LN 处理**：LN 不计入纵连

### 3.2 多押（Chord）
- **定义**：同一节拍点上 ≥ 2 个音符同时按下（BMS 文本同一行即视为同时）
- **最大同时操作数**：8
- **LN 处理**：LN 仅开始点视作普通音符参与多押计数
- **Scratch 处理**：Scratch 视作普通音符参与多押计数
- **不细分押数**：押数差异通过该区间密度自然体现

### 3.3 楼梯（Stair）
- **定义**：满足以下全部条件的连续音符序列：
  - 连续相邻轨道
  - 时值间隔相等
  - 间隔 ≤ 8分音符
  - ≥ 3 个音符且涉及 ≥ 3 个轨道
- **方向处理**：**不考虑方向**，含方向变化的连续序列（如 1→2→3→2→1）算作单个楼梯
- **结束条件**（任一满足即结束）：
  - 出现非相邻跳跃（如 3→5）
  - 出现重复音符（如 3→3）
  - 时值间隔变化
  - 间隔超过 8分音符
- **LN/Scratch 处理**：均不计入楼梯

### 3.4 皿复合（Scratch Combo）
- **定义**：单个小节内同时存在 Scratch 和键盘音符（不要求严格同时）
- **难度数值**：直接参考该小节的难度数值

## 四、难度算法

### 4.1 密度相关指标

| 指标 | 定义 |
|---|---|
| **平均密度** | 按秒计算 + 按小节计算 |
| **加权平均密度（期望值）** | 各小节密度 × (该小节时长 / 总时长) 累加；忽略小节单位上个位数级别的差值 |
| **瞬时峰值密度** | 1 秒滑动窗口扫描，每秒操作数最大值 |
| **持续峰值密度** | 最高的连续 2 秒平均密度（仅作分项展示） |

### 4.2 高密度区间

- **阈值**：密度 ≥ 加权平均密度 × 1.5
- **窗口**：无固定窗口，从密度曲线中取所有连续超过阈值的区间，持续时间即区间长度
- **合并规则**：相邻两区间间隔 < 1 秒时合并为一个区间
- **统计范围**：所有符合阈值的区间

### 4.3 峰值操作要求 (P_op)

- **单区间贡献** = 区间平均密度 × 持续时间（线性，等价于区间内音符总数）
- **整曲峰值操作要求** = Σ(所有高密度区间贡献)

### 4.4 键型复杂度（按小节）

各键型复杂度统一计算规则：

```
C_X = Σ_小节 (该小节密度 × 该小节中 X 键型音符占比)
```

| 符号 | 含义 |
|---|---|
| C_chord | 多押复杂度 |
| C_stair | 楼梯复杂度 |
| C_jack | 纵连复杂度 |
| C_scratch | 皿复合复杂度 |

### 4.5 左右手协调性（仅作统计指标，**不参与难度计算**）

- **分组**：左手 = 1,2,3 号键；右手 = 4,5,6,7 号键（含 LN）
- **判定单位**：2 小节
- **判定规则**：两组音符数量差异达到一个数量级时，判定为左右手压力分配差异大
- **输出**：统计整曲中"压力不均"的 2 小节区间数量

### 4.6 难度加权和（最终公式）

```
总难度 = 0.60·D_avg
       + 0.20·P_op
       + 0.05·C_chord
       + 0.05·C_stair
       + 0.05·C_jack
       + 0.05·C_scratch
```

| 权重 | 维度 |
|---|---|
| 0.60 | 加权平均密度 |
| 0.20 | 峰值操作要求 |
| 0.05 | 多押复杂度 |
| 0.05 | 楼梯复杂度 |
| 0.05 | 纵连复杂度 |
| 0.05 | 皿复合复杂度 |

**量纲处理**：不做归一化，直接加权和；大数值维度对总分的影响在可视化中通过标记说明。

**输出形式**：同时输出**总难度值**（用于排序/筛选）与**各分项数值**（用于雷达图等分项展示）。

## 五、段落划分

- **方式**：固定 15 秒分段（不再做 Intro/Buildup/Drop 等结构识别）
- **用途**：服务于可视化（难度曲线、键型分布堆叠等）

## 六、可视化方案

### 6.1 图表清单

| 优先级 | 图表 | 说明 |
|---|---|---|
| **核心** | 难度曲线图 | 密度折线 + 难度堆叠柱状（含键型分布堆叠） |
| **核心** | 雷达图 | 6 维度对比 |
| **附加** | 总览仪表盘 | 卡片式整曲指标展示 |
| **附加** | 高密度区间标记 | 已合并入难度曲线图（密度线上红色标记） |
| **底层** | 数据列表 | 文字列表展示所有原始数据，置于最下方 |

### 6.2 难度曲线图（核心）

- **窗口**：可切换 **小节** 与 **15 秒段落** 两种粒度
- **构成**（同一图表内）：
  - 密度折线（主曲线，15 秒/小节窗口）
  - 难度堆叠柱状图（同窗口；由 4 种键型加权堆叠形成）
  - 高密度区间在密度线上以**红色**标记

### 6.3 雷达图（核心）

#### 维度（6 轴）

| 轴 | 维度 |
|---|---|
| 1 | 加权平均密度 (D_avg) |
| 2 | 峰值操作要求 (P_op) |
| 3 | 多押复杂度 (C_chord) |
| 4 | 楼梯复杂度 (C_stair) |
| 5 | 纵连复杂度 (C_jack) |
| 6 | 皿复合复杂度 (C_scratch) |

#### 归一化公式

```
设 raw 为该维度原始值，base 为基准值，offset 为初始偏移（=10）
x = ((raw + offset) / base) × 100

norm(x) = x                          (x ≤ 100)
norm(x) = 100 + 50 · log₁₀(x / 100)  (x > 100)
```

> **初始偏移说明**：每维度的原始值先加 `offset = 10` 再做归一化，避免某维度为 0 时雷达图塌缩为单点，保证最小值始终有可视面积。

| x 值 | 归一化值 |
|---|---|
| 0 | 0 |
| 50 | 50 |
| 100 | 100 |
| 200 | 115 |
| 500 | 135 |
| 1000 | 150 |
| 10000 | 200 |

> 表中 `x` 为公式中的中间变量（即 `((raw + 10) / base) × 100`），不是原始值。

#### 各维度基准值（对应雷达图 100）

| 维度 | 基准值 |
|---|---|
| D_avg | 20 |
| P_op | 100 |
| C_chord | 300 |
| C_stair | 300 |
| C_jack | 300 |
| C_scratch | 360 |

### 6.4 用户自定义键型权重

- 提供权重配置接口，让用户根据个人情况自定义各键型相对权重
- **该配置仅影响可视化展示，不影响难度计算**

### 6.5 个人偏好（最擅长 / 最不擅长）

分析前用户可设置两个下拉选项：

| 选项 | 可选值 | 效果 |
|---|---|---|
| **最擅长的配置** | 无 / 多押 / 纵连 / 楼梯 / 皿复合 | 该项雷达值 × 0.80（降低 20%） |
| **最不擅长的配置** | 无 / 多押 / 纵连 / 楼梯 / 皿复合 | 该项雷达值 × 1.30（增加 30%） |

- **仅影响雷达图的 4 项键型轴**（多押、楼梯、纵连、皿复合），不影响平均密度、峰值操作两轴
- **不影响总难度公式**
- 倍率在归一化之后乘上，即 `radarValue = norm((raw + 10) / base) × prefMultiplier`
- 选项变化时立即重新渲染雷达图与数据列表，无需重新上传文件

### 6.6 PDF 结构（紧凑布局）

PDF 仅包含以下章节（页面上仍展示完整 5 章）：

| 章节 | 内容 |
|---|---|
| 第 2 章 | 难度曲线图（15 秒粒度） |
| 第 3 章 | 雷达图 |

**排版**：紧凑排版（缩小 padding、字号、卡片间距），章节间不强制分页，由内容长度自然决定页数。第 1 章（小节粒度曲线）、第 4 章（总览仪表盘）、第 5 章（数据列表）仅在网页上展示，不进入 PDF。

### 6.7 输入输出
- **输入**：网页上传单个 BMS 文本文件
- **流程**：即时分析 + 即时导出 PDF（不保存历史记录）
- **输出文件名**：默认基于谱面文件名

## 七、系统架构

### 7.1 模块划分

| 模块 | 职责 |
|---|---|
| **Parser** | BMS/BME/pms 文本解析 → 原始事件列表 |
| **Normalizer** | 时间轴换算、轨道归一、LN 处理 |
| **PatternDetector** | 键型识别（楼梯/纵连/多押/皿复合） |
| **DensityAnalyzer** | 密度曲线、高密度区间、加权平均 |
| **SegmentAnalyzer** | 15 秒分段统计 |
| **DifficultyCalculator** | 各维度难度计算 + 加权汇总 |
| **Visualizer** | Chart.js 图表渲染 |
| **PDFExporter** | html2pdf.js 导出 |
| **UI Controller** | 页面交互、文件上传、流程编排 |

### 7.2 数据流

```
[文件上传]
     ↓
[Parser] → 原始事件列表
     ↓
[Normalizer] → 标准化事件（时间、轨道、LN 已处理）
     ↓
┌────────────────┬──────────────────┬──────────────────┐
↓                ↓                  ↓                  ↓
[PatternDetector] [DensityAnalyzer] [SegmentAnalyzer]  ...
↓                ↓                  ↓
└────────→ [DifficultyCalculator] ←─┘
                 ↓
           [Visualizer]
                 ↓
          [PDFExporter]
```

## 八、关键决策记录

以下记录方案讨论中的关键决策点及理由：

| 决策点 | 决策 | 理由 |
|---|---|---|
| BMSON 支持 | **不支持**，仅支持 BMS/BME/pms 文本格式 | 简化解析逻辑 |
| LN 持续时间 | 不影响难度 | 简化模型，仅算开始 |
| 楼梯方向 | 不区分 | 简化键型判定 |
| 多押押数细分 | 不细分 | 押数差异由密度自然体现 |
| 复合加成 | 不考虑 | 难度按区间计算，不涉及单音符 |
| 左右手协调 | 仅作统计，不参与难度 | 数值化难以体现真实压力 |
| 段落划分 | 固定 15 秒，不做结构识别 | 服务于可视化即可 |
| 量纲归一化 | 不归一化（雷达图除外） | 大数值是参考必要项 |
| 雷达图归一化 | 100 以下线性，超过取对数 | 保留常规范围细节，压缩极端值 |
| 后端 | 无 | 隐私好、零部署、最稳定 |
